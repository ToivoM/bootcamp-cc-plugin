# Bootcamp CC

A [RuneLite](https://runelite.net) plugin for the Bootcamp CC clan.

The plugin is at an early stage: it has no features yet and makes no network requests.

## Settings

| Section  | Setting | Default | Description |
|----------|---------|---------|-------------|
| Advanced | API URL | (empty) | Base URL of the Bootcamp CC API. Leave empty unless a clan admin tells you otherwise. Not used yet. |

## Privacy

The plugin currently sends no data anywhere. Any future feature that talks to the Bootcamp CC server
will be off by default, will say so in its setting, and will only send your own data.
